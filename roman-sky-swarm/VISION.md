> One-line summary for orientation: **Roman Sky Swarm is a browser-native
> distributed scientific computing platform — BOINC reimagined for the modern
> web** — where volunteer browser tabs fetch only the needed bytes of large
> public astronomy catalogs (Roman, Rubin, IRSA-hosted datasets) over HTTP,
> run declarative SQL/Wasm compute kernels, and return checksummable,
> redundantly-validated results to a coordinator.
>
> Spike 0 (this directory) deliberately builds none of that except the single
> load-bearing primitive: partial-read + deterministic kernel + bit-identical
> hash in a plain browser tab. See `README.md`.
