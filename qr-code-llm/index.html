WHAT FITS IN THE SQUARE?

Learned weights. No lookup table.

A character embedding, a gated recurrent unit, and an output layer predict the next character. The code also carries the alphabet, dimensions, weight scales, and a checksum. The reader supplies only the generic math and QR decoder.
